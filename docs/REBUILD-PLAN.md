# ImageSifter 重构方案

状态：原始规划参考。2.0.0 的实际交付范围、格式限制与操作方式以 README 和 CHANGELOG 为准；工程封面、完整工程打包、集合与重复图片检测留待后续版本。

## 产品目标

参考 Lightroom Classic 的图库、放大、比较、胶片条及标记流程，制作以拍摄批次为单位的本地照片筛选管理工具。保留 ImageSifter 名称，使用原创品牌与视觉资产。首版聚焦选片、比较与整理。

## 工程

- 新建、打开、关闭、切换工程；最近工程、拍摄日期、封面、名称和描述。
- 每次拍摄可建独立工程，工程引用一个或多个照片目录；默认不复制原图。
- 工程保存独立 SQLite 索引、评分、颜色标签、取舍、筛选、当前照片、视图布局与文件操作记录。
- 双击工程文件打开；自动保存；同一工程写入锁；数据库版本迁移和备份。
- 断开的磁盘显示离线状态，可重新定位目录；不得当作删除处理。
- 导出工程记录与包含照片的完整工程包分开说明。只有带齐原图的完整包才能独立迁移；缓存可重建。

建议目录：

```text
拍摄工程/
  拍摄工程.imagesifter
  catalog.sqlite
  previews/
  Rejected/
  backups/
```

## 弃片目录

- 删除按钮和菜单明确命名为“移入弃片文件夹”，不用系统回收站。
- 标记淘汰只改状态；执行移入弃片时才移动文件。
- 默认使用工程的 Rejected 目录，可配置专用位置。
- 按来源目录标识及原相对目录保存，冲突时生成不覆盖的目标名称；排除弃片目录的重复扫描。
- 移动前列出照片和关联 RAW，只有用户选择时才包含关联文件。
- 记录原路径、目标路径、操作状态及配对信息；支持查看、打开弃片目录、单张/批量恢复。
- 同卷优先重命名；跨卷复制到临时目标、校验内容、完成目标后再移除源文件。
- 失败、只读、空间不足、源文件变化、部分完成不得伪报成功；操作日志支持启动后核对和恢复。
- 恢复时遇同名文件不覆盖。弃片不自动清空，首版不提供默认永久销毁操作。
- 同一原图被多个工程引用时，物理移动仍影响其他工程；操作前提示，其他工程可根据文件记录重新定位，不承诺原路径不变。

## 工作台

- 顶部：工程切换、模式、搜索、筛选、整理入口。
- 左侧：目录、收藏集、全部/未筛选/保留/淘汰/弃片分类。
- 中央：网格、放大、双图比较；可调缩略图大小。
- 右侧：文件属性、评分、颜色标签、EXIF，可折叠。
- 底部：胶片条、数量、选中状态、任务进度。
- 深灰中性画布，翡翠青作为主色，琥珀/蓝/紫用于标签与少量导航；照片显示不加染色滤镜。
- 一致的适度圆角、字体层级、图标、悬停与选中反馈；高分屏、多显示器与窄窗口适配。
- P 保留、X 淘汰、U 取消标记、0–5 星级、方向键切图；支持标记后自动前进。

## 加载与格式

- 扫描、缩略图、原图解码与 EXIF 后台执行，任务可取消，有明确失败终态。
- 优先当前可见区域；邻近预加载；内存和磁盘缓存有上限；数据模型与视图分离。
- 保留色彩精度与透明度，尊重 EXIF 方向；缩放不反复分配整张放大位图。
- 首版常见静态格式，后续 GIF/动画 WebP、RAW 嵌入预览及扩展解码能力。
- 进度反馈与轻微淡入，不用阻塞操作的装饰动画；支持减少动态效果。

## 执行与发布

1. 保留原项目快照，建立构建与隔离测试数据。
2. 实现工程、持久化、异步加载和缓存；修复原有崩溃与任务生命周期问题。
3. 实现工作台、快速选片、比较和批量整理。
4. 实现弃片移动、关联文件、恢复和中断恢复验证。
5. 完成 Logo、应用 ICO、图标与高分屏检查，扩展格式与动图。
6. 测试后创建 Stylle/ImageSifter 公开仓库，推送源码和版本标签，创建 GitHub Release，附 Windows x64 便携包及安装包、校验值、说明和第三方授权。仓库名冲突时先核对现有仓库身份。

使用 C++、Qt 和本地 SQLite，目标迁移到 Qt 6 + CMake。打包需核对 Qt/编解码器和现有 easyexif 等第三方许可证，公开源码许可证另行明确，不擅自删除原作者署名。不会发布本地 IDE 配置、用户照片、工程数据库、缓存和个人路径。无需 Docker。

## 验收

- 多工程互不串评分和筛选进度，重启可继续。
- 空目录、损坏图、快速切换目录和退出加载均不崩溃，进度能结束。
- 弃片实际进入专用目录，可恢复；冲突不覆盖，失败不移除列表，不丢文件。
- 跨卷、中断、RAW 配对、离线原图及共享原图有清楚处理。
- 大目录不会一次性解码全部原图，长列表和缩放有内存上限。
- Release 基于已测试的版本提交，清楚列出实际支持的平台和格式。
