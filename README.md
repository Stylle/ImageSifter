# ImageSifter

本地照片筛选与文件整理工作台，使用 C++17、Qt 6 和 SQLite。参考 Lightroom Classic 的图库、放大、比较与胶片条工作流；不上传照片，无账户、云服务或 Docker 依赖。

## 下载与使用

从 [GitHub Releases](https://github.com/Stylle/ImageSifter/releases) 下载 Windows x64 安装包或便携 ZIP。解压便携包后运行 `ImageSifter.exe`，必须保留随包的 DLL 和插件目录。安装包按当前用户安装，可选桌面快捷方式和 `.imagesifter` 工程文件关联。当前验证平台为 Windows 11 x64；不提供未经验证的 macOS/Linux 安装包。版本 2.0.0。

1. **新建工程**：为一次拍摄命名，选择存放位置；程序创建同名工程文件夹。
2. **添加照片来源**：引用一个或多个照片文件夹，默认包含子目录，不重复复制原图。
3. **选片**：网格、放大或双图比较；设置保留/淘汰、0–5 星和颜色标签。支持批量选择、文件名搜索、评分/颜色/格式过滤及排序。
4. **整理**：在右侧或“工程 → 文件整理”中分离 JPG/RAW，或单独移除一种格式。
5. **继续工作**：打开工程目录中的 `Project.imagesifter`。标记立即保存，布局和当前位置在正常切换/关闭时保存；最近工程记录保存在当前设备。

窄窗口自动收起侧栏，可在“工程”菜单重新显示；双击图片进入放大，双击预览切换适应/实际像素。比较模式可固定参考图、同步缩放和平移。旋转仅影响预览，不重写原图。动图可通过“工程 → 播放/暂停动图”控制。

## JPG / RAW 整理与弃片

**分离 JPG 与 RAW**：将当前筛选范围的文件移动到所选目录下的 `JPG`、`RAW` 两个文件夹。内部保留来源标识和原相对目录以防同名覆盖。保留评分、取舍和配对关系。

**普通移除**：将所选照片及其关联 JPG/RAW 移入工程专用的 `Rejected` 文件夹；不使用系统回收站，不永久删除。确认框会列出实际处理的文件。配对基于来源目录、相对目录及不区分大小写的同名文件；分离后配对记录仍保留。不按相近拍摄时间猜测关联，文件被重命名后不会凭空推断配对。

**单格式清理**：`移除全部 JPG` 或 `移除全部 RAW` 只影响当前筛选范围的指定格式，配对的另一种格式保留。不是永久清空。

弃片内部按 `JPG`、`RAW`、`Images` 分类，可在左侧“弃片文件夹”中直接查看、格式筛选、选择并恢复。恢复到移除前的位置；已经分离整理的照片恢复到整理后的目录。原位置有同名文件时不覆盖。其他工程若引用同一个物理文件，也会受到移动影响，需要重新定位来源目录。

`恢复整理前的位置` 将未弃片的文件恢复到各自最近整理前的位置。文件操作有日志和内容校验；中断后重新打开工程会核对状态。若两份文件都存在等情况无法确定，会保留副本并提示检查“文件操作记录”，不会自动删除其中一份。取消整理在文件之间生效，当前文件先安全完成。没有自动清空弃片功能。

## RAW 与图片格式

- 静态图：JPG/JPEG、PNG、BMP、WebP、TIFF 等，由随包 Qt 插件解码。
- 动图：GIF、插件支持的动画 WebP；离开预览区会暂停，切换图片会释放播放器。
- RAW：使用 LibRaw 0.22.3，覆盖 CR2/CR3/CRW、NEF/NRW、ARW/SR2/SRF、RAF、ORF、RW2/RWL、PEF、SRW、DNG、3FR/FFF/IIQ 等不同品牌后缀；后缀不区分大小写。异常后缀也会对可识别的 RAW 文件头进一步用 LibRaw 验证。
- RAW 优先读取相机内嵌预览，没有可用预览时尝试半尺寸解码；实际像素表示当前预览像素，不代表完整 RAW 显影精度。本软件不提供 Lightroom 的显影模块。
- 并非每一种新相机、压缩编码或损坏 RAW 都可解码，具体以 [LibRaw 支持列表](https://www.libraw.org/supported-cameras) 为准。无法预览会明确提示，文件仍可管理。HEIC/AVIF 未随本版本提供解码器。
- 颜色会尽可能转换到 sRGB；不宣称专业软打样或完整显示器 ICC 工作流。超大图受解码器内存限制。

## 工程与备份

工程目录包含 `.imagesifter` 标识、`catalog.sqlite`、可重建的 `previews`、`Rejected` 和 `backups`。SQLite 数据包含路径、标记、配对和移动日志，禁止当作缓存清除。单个工程只能由一个写入窗口打开。

“备份工程记录”创建一致的 SQLite 备份，**不包含外部原图**。完整迁移请关闭工程，复制整个工程目录及其引用的照片目录；打开后可右键来源目录“重新定位”。不得在程序运行时单独替换 SQLite 文件或只复制主数据库忽略 WAL。磁盘离线只显示离线状态，不会把记录当作已删除。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| G / E / C | 网格 / 放大 / 比较 |
| P / X / U | 保留 / 淘汰 / 清除取舍 |
| 0–5 | 星级 |
| ← / → | 上一张 / 下一张 |
| Delete | 移入弃片（弃片分类中为恢复） |
| Ctrl+Z | 撤销最近一次标记 |
| F | 切换全屏 |

文本输入和对话框不会触发上述选片快捷键。

## 从源码构建

需要 Qt 6.5+（正式包使用 6.8.3）、匹配的 C++17 编译器、CMake 3.21+ 和 Ninja。Qt 模块：Core、Gui、Widgets、Sql、Concurrent、Test、Svg；另安装 `qtimageformats`。首次配置会下载 SHA-256 固定的 LibRaw 源码，可通过 CMake 的 `FETCHCONTENT_SOURCE_DIR_LIBRAW_SOURCE` 指向已下载源码。

```sh
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=/path/to/Qt
cmake --build build
ctest --test-dir build --output-on-failure
```

Windows 打包参见 [构建发布说明](docs/BUILD-RELEASE.md)。测试仅生成隔离图片和工程，不使用用户照片，不把示例数据植入正式程序。
